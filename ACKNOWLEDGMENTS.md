# Acknowledgments

This project, **RogerSlides**, builds upon the [PPT Master](https://github.com/anthropics/ppt-master) skill framework for AI-driven presentation generation.

PPT Master provides the core pipeline — multi-role collaboration (Strategist → Image_Generator → Executor), SVG-to-PPTX conversion, quality checking, and the full post-processing workflow. RogerSlides extends it with CICC brand specifications, investment research layout conventions, and analyst-driven content enrichment.

We gratefully acknowledge the PPT Master project and its contributors for providing the foundation that makes this work possible.
